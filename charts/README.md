# Charts

Cross-city figures, separate from the QGIS map plates in `maps/`.

Furniture matches the plates: white page, thin black neatline, Arial title box, 12 pt bold footnote, `©Wisdom Akpabio`. Rebuild with `python -m proximity.charts`.

| File | What it shows |
|---|---|
| `pipeline` | Inventories, the walk, and the scores reported |
| `f15_vs_density` | F15 against people per km² |
| `f15_by_n` | F15 at a choice of 1, 5 or 20 nearby services |
| `nstar_curves` | Coverage as optimally sited clinics are added |

Write-up: [`notes/results.md`](../notes/results.md). PDF: [`notes/fifteen_minute_access_nigeria.pdf`](../notes/fifteen_minute_access_nigeria.pdf).
